# 让她会发表情包、发语音、戳一戳

> 这几样东西的共同点：它们**不是消息**，是动作。
> 用工具调用去做，十次有九次她不会调；用文本标记去做，她自然而然就用了。

---

## 一、问题：为什么工具调用不行

给 agent 注册一个 `send_sticker` 工具，然后指望它在聊天中间自己想起来调用 —— 实测几乎不会发生：

- 提示词里写了"可以发表情包"，她**只在被直接要求时**才调
- 调了之后是一条独立的工具消息，节奏上是断的
- 工具调用失败会污染上下文（她看到"调用失败"，下次更不敢用）
- 延迟明显：一次工具往返 1~3 秒，表情包应该是"顺手甩出来的"

真人发表情包的时候不会先想"我要调用发表情包的接口"。**她是想说什么，顺手带一个。**

---

## 二、做法：把动作写成文本标记

人格里教她这么写：

```
[[表情包:无语]]
[[小黄脸:12]]
[[戳一戳]]
[[语音:你干嘛呢|tired]]
```

发送层在**发出去之前**把这些标记抽掉，正文照发，动作另外执行。

| 标记 | OneBot 动作 | 说明 |
|---|---|---|
| `[[表情包:名字]]` | `send_private_msg` + `{type:"image"}` | 从她自己的收藏里按名字模糊匹配 |
| `[[小黄脸:id]]` | `send_private_msg` + `{type:"face"}` | QQ 自带的黄脸 |
| `[[戳一戳]]` | `friend_poke` | 只能私聊 |
| `[[语音:文本|情绪]]` | 先 TTS 再发语音 | 文本里带情绪标签提词 |

**关键点：解析失败必须降级成纯文本，不能报错。**
标记写错一个名字，最多是这次没发表情包，不能让她整句话发不出去。

## 三、实现骨架

```js
const MARKERS = [
  { re: /\[\[表情包[:：]([^\]]+)\]\]/g, kind: "sticker" },
  { re: /\[\[小黄脸[:：](\d+)\]\]/g,    kind: "face" },
  { re: /\[\[戳一戳\]\]/g,              kind: "poke" },
  { re: /\[\[语音[:：]([^\]|]+)\|([^\]]*)\]\]/g, kind: "voice" },
];

export function extractMarkers(text) {
  const extras = [];
  let clean = text;
  for (const m of MARKERS) {
    clean = clean.replace(m.re, (...g) => {
      extras.push({ kind: m.kind, args: g.slice(1, -2) });
      return "";
    });
  }
  return { clean: clean.trim(), extras };
}
```

发送顺序：**先文字，后动作**。反过来的话，她的话会被一个表情包打断。

## 四、三个必须知道的坑

### 坑 1：`file:///C:/...` 会被 QQ 拒绝

```js
// ✗ retcode 1200，中文路径尤其容易挂
{ type: "image", data: { file: "file:///C:/Users/…/无语.png" } }

// ✓ 直接给本地绝对路径
{ type: "image", data: { file: "C:\\Users\\…\\无语.png" } }
```

用 `rawAction` 发，别走插件封装。**路径里有中文没关系，前缀 `file://` 才是问题。**

### 坑 2：只发了动作、没返回 messageId，网关会重试

OpenClaw 网关认为"没有 messageId = 没送到"，于是反复重投同一条消息。
所以：**只要这次带标记，就要返回一个合成的 messageId**（`extra-…` / `voice-…`），让它认为投递完成。

现象是：她一句话连发三遍。

### 坑 3：额度必须写在发送层，不能写进人格

人格里写"一天最多发 5 张表情包"是没用的 —— 她不会数。
在发送层做：

- 概率：短句（≤8 字）才 7% 顺手带一张
- 每日上限：表情包 5 张、戳一戳 2 次
- 冷却：表情包 12 分钟、戳一戳 30 分钟
- 状态写文件，跨进程共享

## 五、频率：多少才像真人

我们统计了自己 72 小时、244 条助手消息：

| 类型 | 次数 | 占比 |
|---|---|---|
| 语音条 | 11 | 1/22 |
| 表情包 | 4 | 1/61 |
| 小黄脸 | 2 | 1/122 |
| 戳一戳 | 3 | 1/81 |

**比真人少，但"会"比"多"重要。**
一个从来不发语音的角色，突然发一条语音，比每五条发一条更像活的。

> 教训：先查**全部会话**再下结论。我们一度只看主会话，得出"表情包 0 次"，
> 差点把已经跑通的机制当没做。

## 六、人格里怎么写

不要写成规则清单，写成**她的习惯**：

```
怎么发（2.5）

你说话不是一整段。想到一句发一句。
偶尔用一个动作，不用解释：
  困了 → [[小黄脸:8]]
  无语 → [[表情包:无语]]
  想让他看 → [[语音:你过来看这个|tired]]

动作是顺手带的，不是每次都有。
一条消息最多带一个标记。
```

**给例子，别给比例。** 比例她记不住，例子她照着学。
