# 踩过的坑（都会让角色"人格崩掉"）

> 这几条都不是提示词能修的。它们的共同点是：**你从聊天记录里看不出来，只有真聊才发现。**

---

## 坑 1：会话分裂 —— 她不承认自己说过的话

### 症状

```
她（主动）：我感觉要死了
你：咋了
她：我没咋啊，你这一惊一乍的
你：？？ 那你说自己要死了
她：我啥时候说要死了，你做梦呢吧
```

**她不是嘴硬，她真的以为自己没说过。**

### 原因

主动消息、连发补句、未回复跟进 —— 这些"她自己发起"的消息，如果走了**独立的会话**，她说完就扔了。

你回复时走的是主会话，主会话里根本没有那句话。

我们查出来的分布：

```
[会话A] 我感觉要死了          ← 主动消息
[主会话] 我没咋啊             ← 你回她
[会话B] 你睡了吗 三点半了
[会话C] 鼻子还堵着 睡不着
[会话D] 药吃了没
```

**一整段对话，其实是五个互不相通的对话。**

### 修法

所有"她主动说"的路径，都必须落到**同一个会话**：

```js
// ❌ 每条主动消息开一个新会话
sessionKey: "proactive:" + slot + ":" + date

// ✅ 用主会话
sessionKey: "agent:main:main"
```

### 代价

主动消息的"提示词"（比如「你刚上完第三节课」）会留在对话历史里。

**这个取舍值得** —— 记忆连续比提示词干净重要一百倍。

## 坑 2：`Attachment:` 和 `MEDIA:` 不是一回事

### 症状

发出去的表情包变成一段文字：

```
?
Attachment: C:\Users\...\05_wenhao.png
```

用户看到的是路径，不是图片。

### 原因

`Attachment:` 是**入站**格式（用户发给 agent 时，附件怎么表示）。

**出站（agent 发给用户）要用 `MEDIA:`。**

而且格式极严：

```
✅ 正确
快睡

MEDIA:C:\path\to\sticker.png

❌ 挤在一行
快睡 MEDIA:C:\path\to\sticker.png

❌ 加粗
**MEDIA:**C:\path\to\sticker.png

❌ 写在代码块里
\`\`\`
MEDIA:C:\path\x.png
\`\`\`
```

### 更麻烦的：它会自我复制

历史上的错误写法会**变成模型的先例**，它会照着抄。

我们改成 `MEDIA:` 之后，模型还是写 `Attachment:` —— 因为对话历史里全是旧的错误示范。

**改语法的时候，必须连历史记录一起清。**

## 坑 3：推理模型把思考过程发出来

### 症状

```
她：Wait — his sequence at 01:41 "在吗", then me at 01:42 "在"... 
    He was just checking if I'm there. As Dong Xiaohan at 1:42 AM...
    嗯，躺着呢，你干啥呢
```

英文思维链混进正文，而且一次要 **97 秒**。

### 原因

DeepSeek V4 / Kimi K3 这类是**推理模型**。如果请求里没正确关闭思考：

- 思考 token 会吃掉输出预算 → 空回复
- 或者思考内容直接混进正文

### 修法

**聊天场景优先用非推理模型。** 需要推理模型时，必须显式关掉：

```json
{ "model": "deepseek-flash", "thinking": { "type": "disabled" } }
```

或者按框架的方式设置 thinking 档位（不同框架参数名不同，要查）。

### 判断标准

跑完一轮之后看：

- 有**空回复** → 推理吃掉了预算
- 回复里出现**成段的英文** → 思考泄漏了

**两个都是推理模型的典型症状，不是提示词问题。**

## 坑 4：审计用的会话会污染下一次审计

### 症状

审计做了两轮，第二轮结果好得可疑 —— 因为它**在抄自己第一轮的答案**。

### 原因

模型的"先例效应"：它会跟自己前面说过的话保持一致。

如果审计工具每次用同一个 session，第二轮看到的上下文里有第一轮的输出。

**这跟"我是 Kimi"那个坑是同一个机制。**

### 修法

每次审计用**全新的会话**：

```js
const SESSION = "agent:main:audit-" + Date.now();   // 每次不同
```

### 同一个机制的另外两个表现

1. **角色承认自己是 AI** —— 因为历史里真的有三次「我是 Kimi」。**改提示词没用，要改历史记录。**
2. **错误格式自我复制** —— 见坑 2。

**记住这条：模型跟着先例走，不是跟着规则走。**

## 坑 5：数据库是 WAL 模式，只读连接看不到新数据

### 症状

你查数据库，看到的是一小时前的状态。后台明明已经写进去了。

### 原因

SQLite 的 WAL 模式：新数据先写进 `-wal` 文件，稍后才合并进主库。

**只读连接可能读不到 WAL。**

### 修法

诊断脚本别用只读模式：

```js
// ❌
new DatabaseSync(path, { readOnly: true })

// ✅
new DatabaseSync(path)
```

## 一条通用经验

> **所有"她说了但否认"、"她重复发同一句"、"她突然变英文"这类问题，
> 九成不是提示词，是数据流。**

先看**她实际收到了什么上下文**，再改人格。

改人格是最后一步，不是第一步。
