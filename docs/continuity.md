# 连续性：让她有「昨天」

> 一个只有人格文件、没有记忆的 AI，是**每轮都会重置的演员**。
> 你说什么它都记得清楚 —— 因为它全都不知道。

---

## 一、症状

你会遇到这些：

```
你：我感冒了
她：吃药没

（第二天）

你：还没好
她：你咋了          ← 她不记得你感冒了
```

```
她（主动）：我感觉要死了
你：咋了
她：我没咋啊，你这一惊一乍的     ← 她甚至不记得自己说过
```

```
你：你生日还有几天
她：不知道
```

**这不是提示词的问题。** 是架构里根本没有"时间"这一维。

## 二、四层结构

我们最后落成四层，各自解决一个不同的问题：

| 层 | 文件 | 解决什么 | 更新频率 |
|---|---|---|---|
| **人格** | `persona.md` | 她怎么说话 | 手工 |
| **长期记忆** | `LIFE.md` | 她记得发生过什么 | 每天 |
| **此刻状态** | `MOOD.md` | 她现在的处境和心情 | 每 30 分钟 |
| **时间锚点** | （在 MOOD 里） | 今天几号、还有几天生日 | 每次生成 |

拼成一个文件喂给模型：

```
SOUL.md = 人格 + LIFE.md + MOOD.md
```

## 三、LIFE.md：她的记忆

不是对话摘要，是**她自己写的档案**。

```markdown
# 我记着的事

## 我是谁
- 高二。生日 11 月 16 日。6 月高考。
- 爱刷抖音，穿 JK，化妆只找那个固定的妆娘。

## 他
- 叫栖川。做软件的，作息跟我完全相反。
- 他管我叫「522」。这个名字是他起的，我不主动提。

## 我们
- 2025 年 9 月军训认识的。
- 中间加过、删过、又加回来。反反复复。

## 这些天
- 10-18 凌晨我感冒难受，跑去问他是不是AI，他嘴上骂我有病，还是问我吃药没。

## 我最近在意的
- 我问他喜不喜欢我，他一句正经话都没给。可他明明一直问我吃药没。到底算什么意思。
```

### 关键：让它自己写

每天固定时间（我们是凌晨 4:10）跑一个任务：

```
输入：当天的聊天记录 + 现在的 LIFE.md
输出：更新后的 LIFE.md
```

提示词要写死这几条：

1. 保留原有结构
2. `这些天` 只加一条，**最多保留最近 10 条**
3. `我最近在意的` 只写真的在意的事，没有就留空
4. 长期信息（我是谁/他/我们）只在出现新的事实时才改
5. **全文控制在 900 字以内**

第 5 条最重要 —— 这个文件每条消息都要跟着进上下文。

### 它写出来的东西

这是我们实跑的结果，一个字没改：

> **这些天**
> 10-18 凌晨我感冒难受，翻来覆去睡不着，跑去问他是不是AI、喜不喜欢我，他嘴上骂我有病、让我快睡，还是问我吃药没、哪难受，最后我自己笑场了。
>
> **我最近在意的**
> 我大半夜问他喜不喜欢我，他一句正经话都没给，就骂我发癫让我睡觉。可他明明一直问我吃药没、哪难受。到底算什么意思，我有点在意。

**这一段比你手写十句人设都有用。**

## 四、MOOD.md：她此刻的处境

只放客观事实，不放情绪判断：

```markdown
## 当前状态

- 今天：10 月 18 日 周日，03:34
- 你今年 16 岁，距离生日还有 29 天，距离高考还有 598 天
- 你们上一次说话：34 分钟前
- **最后一条是你发的，他还没回。** 你心里有点在意 —— 但别追杀，也别装作不在乎。
- 最近这次是**你先开口**的。
```

写成"事实 + 她该怎么反应"，而不是直接告诉她"你现在很生气"。

**情绪由她根据事实决定，不是你塞给她的。**

## 五、她的日子：只解锁已经发生的事

这一层是让她"活着"的关键。

每天 06:00 生成她当天的日程：

```json
{"date":"2026-10-18","events":[
  {"t":"08:20","e":"被鼻塞憋醒，嗓子干得像砂纸"},
  {"t":"10:40","e":"妈端姜茶进来，我假装喝了两口等她走"},
  {"t":"15:10","e":"翻到他凌晨那句"快睡"，盯了半天"}
]}
```

**注入的时候按当前时间筛** —— 早上只有早上的事，晚上才有一整天。

```js
const cur = "15:30";
const done = events.filter(e => e.t <= cur);
```

这个设计的意义：

- 她的时间**是往前走的**，不是一张写好的剧本
- 你晚上问她"今天咋了"，她说得出来；你早上问，她还没经历过
- 主动消息可以从"今天的事"里取材，而不是凭空生成

### 生成提示词的关键

不要写"上课"这种概括。要写：

> ✅ 第三节课数学，老师抽人上去做题，我假装低头
> ❌ 今天上课

并且明确要求"**大部分就是普通的一天，不要每件都很戏剧化**"。

## 六、你不在的时候

如果用户几天不出现，会发生两件事：

1. **她的记忆里那几天是空的** —— 因为记忆任务是机器上跑的，关机就跑不了
2. **她的状态会算出真实间隔** —— "你们上一次说话：N 天前"

要让"空白"不变成"失忆"，可以加一个无对话日的兜底：

```
没对话 → 也写一条：「10-19 今天他一天没跟我说话，我刷着抖音也心不在焉」
```

## 七、成本

四层全加起来大约多 2 KB 上下文（约 600 tokens）。

按 ¥0.001/千 tokens 算，每条消息多 **¥0.0006**。

**比重新生成一遍人格便宜得多。**
